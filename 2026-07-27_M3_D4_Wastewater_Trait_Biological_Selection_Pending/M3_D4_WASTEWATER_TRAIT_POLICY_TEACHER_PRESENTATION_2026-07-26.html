SOFT EVIDENCE

提示，不删除

用于解释匹配度、排序参考和 uncertainty。即使不匹配，候选仍保留，供后续 证据与人工复核。

Why not hard now

为什么当前证据不能直接自动剔除

ID 未闭合

Tax ID API 10/10 返回 404

  • documented `/api/v1` probes：16/16 HTTP 404。
  • working route 使用 species-name summary。
  • summary 对象没有 tax_id。
  • 不能从 species 静默继承到 strain。
生产数据面未闭合

没有 official versioned snapshot

  • 5/5 summary 在有界探测中 HTTP 200。
  • 3/3 repeat bodies 字节一致。
  • 观察到 1 次 transient TLS timeout。
  • 观察到 HTTP 429：0 次；不代表 unlimited；rate limit = UNKNOWN。
共识冲突

43/597 = 7.202680%

`No robust majority` 表示来源没有形成稳健多数，必须进入 uncertainty； 不能解释成“不具备该 Trait”。这是五样本记录比例，不是全库率。

数值证据不足

有 median 不等于有完整生长区间

  • 多个数值边界记录主要是 AI-derived。
  • 稀疏样本 Q6BQK1 只有 9 条记录。
  • 缺任一 min/max 不能构造区间。
  • 单位与记录类型必须通过 validator。

unknown

数据缺失、ID 未对齐或证据不足；不等于生物学阴性，不允许 hard reject。

not_applicable

当前证据链无法归属该 Trait；不等于该微生物不存在该性状。

No robust majority

聚合来源无稳健多数；进入 uncertainty，不作负证据。

is_ai

与 majority_label 独立；当前可作标记后的 soft，不能触发未来 hard。

safety/pathogenicity 在三个选项中始终是 soft warning + mandatory manual review； biofilm 在 0/5 覆盖下始终 unused / unknown；广义 wastewater metabolism 只能作 contextual soft，不能替代反应—酶证据链。

Future deterministic rules

  • AI、缺失或冲突记录不触发 hard。

数值 Trait：只认完整区间无交集

valid minimum + maximum→ organism interval∩ confirmed scenario interval→ empty = conflict
  • temperature：Celsius。
  • pH：pH。
  • salinity：% NaCl (w/v)。
  • 缺一侧边界、只有 growth median 或混合单位：soft/unknown。
  • 单维相容不等于整体适合污水工艺。
